# Astra Studio — Release 4.0

Дата: 2026-09-24

## Рабочая папка

- Новая внутренняя рабочая папка содержит примеры только для Java, Python, C++, JavaScript, HTML и CSS.
- Старые автоматически созданные примеры TypeScript, Luau, GDScript, PHP, PowerShell, C# и SQL переносятся в `legacy_workspace_backup`, а не удаляются безвозвратно.
- Дерево скрывает расширения отключённых языков, но продолжает показывать README и нейтральные файлы конфигурации.
- Пользовательские рабочие папки и их файлы миграция не изменяет.

## Дерево проекта

- Удалено ограничение максимальной ширины 420 px.
- Панель больше не скрывается автоматически из-за DPI, ширины окна или открытой панели инструментов.
- Ширина сохраняется штатным механизмом размеров splitter и восстанавливается при следующем запуске.

## Запуск и остановка

- Отдельная малозаметная кнопка Stop убрана из боковой панели.
- После начала компиляции или запуска основная кнопка `Запустить` превращается в `Остановить`.
- Кнопка отменяет компиляцию либо завершает запущенную программу и автоматически возвращается к виду `Запустить` после завершения, ошибки или отмены.
- Клавиша F5 использует тот же переключаемый жизненный цикл.
