# Astra Studio — Release 3.17

- Исправлена корневая ошибка C++: неудачная компиляция больше не считается отсутствием компилятора. GCC/Clang diagnostics попадают в Problems и подсвечивают точную строку кода.
- Настройки дизайна упрощены: Astra/Angel 404 стали единым профилем, а множество повторяющихся blur/transparency-регуляторов объединено в общую прозрачность панелей и размытие обоев.
- Обои по-прежнему ограничены редактором и консолью; масштаб остальных панелей от них не зависит.
- Выбор значка и создание/обновление ярлыка перенесены в `Настройки` → `Ярлык Windows`. Установщик языков больше не создаёт ярлык.
- Удалены спорная «Имитация ввода», её клавиатурный шаблон и неиспользуемые blocking-компиляторы; рабочие async-пути сборки сохранены.
- Java, Python, C++, JavaScript, HTML и CSS остаются в основном интерфейсе. Отложенные языковые движки не вырезаны.
