# Astra Studio — Release 3.20

Дата: 2026-09-24

## Исправлено

- Настройки открываются отдельной полноразмерной страницей внутри главного окна Astra Studio. Редактор, дерево проекта и боковые панели не сжимают настройки.
- Обои редактора и консоли рисуются один раз на общей рабочей поверхности. Плиточное повторение и двойное изображение удалены.
- Панель дерева проекта получила минимальную ширину 270 px, непрозрачный фон, отдельную двухпиксельную рамку и устойчивый разделитель.
- Java-подсказки после `System.` теперь содержат `out`, `err` и `in`; цепочки `System.out.` и `System.in.` показывают методы соответствующих потоков.

## Автодополнение шести языков

- Java: системные потоки, стандартные коллекции, строки, файлы, потоки данных, concurrency, HTTP и функциональные интерфейсы.
- Python: расширенные builtins, исключения, стандартные модули и контекстные методы коллекций, `pathlib`, `os`, `json`, `asyncio`, `typing` и других модулей.
- C++: контейнеры, алгоритмы C++20/23, smart pointers, потоки, filesystem, threading, chrono, ranges, format/print и автоматические `#include`.
- JavaScript: коллекции, Promise, Web API, DOM, console, storage, Date, RegExp, Object, Number и методы строк/массивов.
- HTML: полный основной набор современных элементов, void-элементы, closing-tag completion и расширенные глобальные/форменные/медийные атрибуты.
- CSS: существенно расширенный набор свойств и контекстные значения для `display`, flex/grid, position, overflow, cursor, typography и background.

Встроенный каталог остаётся быстрым offline fallback. Для символов зависимостей и точных типов проекта используется существующий LSP-режим Astra Studio через `Ctrl+Space`.

## Совместимость

- Поддерживаемые языки интерфейса не изменены: Java, Python, C++, JavaScript, HTML и CSS.
- Старые скрытые реализации языков не удалены.
- Публичный stable-канал обновлений и транзакционный updater сохранены.
