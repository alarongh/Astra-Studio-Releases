# Astra Studio — Release 3.16

- Обновление приложения стало транзакционным: предыдущая рабочая сборка сохраняется, новая проверяется после запуска, ранний сбой автоматически откатывается.
- Исправлено обновление из папок с именами вида `Astra Studio 3.15`; приложение больше не закрывается из-за ложной проверки имени каталога.
- JavaScript, HTML и CSS возвращены в основной интерфейс вместе с Java, Python и C++.
- Добавлены контекстные подсказки Python, JavaScript/Web API, HTML-тегов и атрибутов, CSS-свойств; методы вставляют курсор внутрь скобок.
- Улучшено управление completion: Tab циклически выбирает, Space/Enter подтверждают, стрелки перемещаются по списку, окно подсказок не выходит за узкий редактор.
- Добавлены умный Enter/автоотступ, парные скобки и кавычки, Tab/Shift+Tab для выделенного блока и умный Backspace.
- Добавлено сворачивание функций в поле номеров строк.
- Синтаксические и внешние диагностики подчёркивают точную строку в редакторе; Python traceback добавляет строку ошибки в Problems.
- Обои ограничены областью редактора и консоли. На узком окне дерево проекта временно скрывается при открытой панели инструментов и восстанавливается после её закрытия.
- Экспериментальная «Имитация ввода» удалена из пользовательского интерфейса; внутренние реализации отложенных языков сохранены.
