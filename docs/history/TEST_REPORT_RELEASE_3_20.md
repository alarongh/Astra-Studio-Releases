# Astra Studio Release 3.20 — Test Report

Дата: 2026-09-24

## Автоматическая проверка

- Python compile gate: `main.py` и `core/language_completion.py` компилируются без синтаксических ошибок.
- Release 3.20 regression suite: полноэкранные настройки, единые неповторяющиеся обои, рамка дерева и контекстное автодополнение всех шести языков.
- Полный pytest gate: `293 passed, 2 skipped, 88 subtests passed`.
- C++23 runtime gate выполняется через ASCII-временную папку, чтобы исключить ограничение MSYS2 linker на кириллический путь OneDrive.
- Native Windows caption/SC_CLOSE gate выполняется с обычным Windows Qt backend, не с `offscreen`.
- Production EXE запущен из `dist/Astra Studio`; процесс отвечал, заголовок `Astra Studio — Release 3.20` подтверждён.

## Визуальная проверка

Qt-снимки исходной версии созданы для 1366×768 и 1600×900:

- настройки занимают всю страницу приложения и имеют собственную кнопку возврата;
- редактор и дерево не видны под страницей настроек;
- Angel 404 присутствует как одно изображение на общей поверхности редактора и консоли;
- дерево проекта находится в отдельной непрозрачной рамке.

## Ограничение SmartScreen

Предупреждение «Неизвестный издатель» относится к подписи Windows. Кодовая правка не создаёт доверенную репутацию файла: для её устранения нужен сертификат code signing и подписанная сборка.
