# Astra Studio — Release 3.19

Дата: 2026-09-24

## Исправлено

- Канал обновлений больше не зависит от того, смогла ли portable-сборка найти `update_channel.json`: официальный публичный HTTPS manifest используется как безопасный встроенный fallback.
- `scripts/create_desktop_shortcut.ps1` теперь действительно включается в PyInstaller onedir-сборку; поиск PowerShell имеет системные Windows fallback-пути.
- Панель настроек получает адаптивную ширину на ноутбуках. При открытой боковой панели дерево проекта временно освобождает место, а на очень узких окнах автоматически сворачивается основная навигация.
- Обои редактора и консоли отрисовываются фиксированной плиткой 1100×620 с постоянным смещением композиции. Масштаб и положение рисунка больше не зависят от размера окна или разделителей.
- Обработчик клавиш установлен и на popup автодополнения. Tab циклически выбирает варианты, Space подтверждает выбранный вариант, а обычный Space больше не пропадает при открытом списке.

## Сохранено

- Шесть видимых языков: Java, Python, C++, JavaScript, HTML и CSS.
- Транзакционное обновление с резервной копией, health-check и автоматическим откатом.
- Диагностика ошибок исходного кода без ложного предложения переустановить уже работающий язык.
