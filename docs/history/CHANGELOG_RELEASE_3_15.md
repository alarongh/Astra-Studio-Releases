# Astra Studio — Release 3.15

- Сохранены исправления обновлятора 3.14: native working directory меняется до замены portable-папки; при ошибке прежняя версия запускается снова и показывает журнал.
- Во всех пользовательских языковых списках остаются только Java, Python и C++.
- Дополнительно скрыты отложенные языки в LSP-таблице, мастере проектов и фильтрах диалога открытия файлов.
- Старые проекты и файлы отложенных языков не удаляются: внутренние реализации, распознавание расширений и код поддержки сохранены.
- Массовая установка, проверка и обновление инструментов ограничены Java, Python и C++.
- Публикация и feed используют публичный репозиторий `Astra-Studio-Releases`.
