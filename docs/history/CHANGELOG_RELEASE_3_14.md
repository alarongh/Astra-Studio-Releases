# Astra Studio — Release 3.14

## Обновление приложения

- Устранено тихое закрытие Astra при установке обновления: detached updater теперь запускается вне portable-папки и явно покидает её перед заменой файлов.
- При ошибке обновления запускается сохранённая рабочая версия и показывается сообщение с путём к журналу.
- Интеграционный Windows-тест воспроизводит установку при исходной рабочей папке внутри `Astra Studio`.
- Публичный репозиторий переименован в `Astra-Studio-Releases`; имя, описание, feed и ссылки больше не выглядят приватными.

## Языки и установщик

- В интерфейсе оставлены только Java, Python и C++.
- JavaScript, HTML, CSS и остальные реализации не удалены и продолжают храниться в коде для следующих этапов.
- Восстановление старой настройки скрытого языка переводит новый файл на текущий поддерживаемый язык.
- Страница установщика, проверка и массовое обновление ограничены Java, Python и C++.
- Создание ярлыка по-прежнему использует текущую запущенную portable-папку, а не старую установленную копию.

## Проверка

- Полный pytest/Windows gate, реальная замена portable-папки, запуск EXE и публичная загрузка проверяются перед публикацией.
