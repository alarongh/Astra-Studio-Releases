# Astra Studio — Release 3.18

- Python, Java, C++ и JavaScript теперь используют единое правило: если компилятор/интерпретатор запустился, его ненулевой код считается ошибкой кода, а не отсутствием языка.
- Вывод `py_compile` и `node --check` разбирается в Problems с точными строкой и позицией.
- Python traceback, Java stack trace и Node.js runtime error подсвечивают строку исходника и не предлагают переустановку среды.
- HTML и CSS проверены отдельно: они не требуют компилятора и не могут открыть установщик языка. Для строгой project-level проверки сохранены Prettier/ESLint и LSP.
- Исправления 3.17 по упрощённым настройкам, ярлыку и C++-диагностике сохранены.
