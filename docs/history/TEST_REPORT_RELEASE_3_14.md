# Astra Studio Release 3.14 — Test Report

## Исправленные пользовательские дефекты

- Обновлятор больше не наследует рабочую папку запущенной Astra и может заменить каталог после закрытия GUI.
- При неудаче прежняя версия запускается повторно, а ошибка становится видимой пользователю.
- GitHub-публикация использует публичный репозиторий `Astra-Studio-Releases` без вводящего в заблуждение слова `Private`.
- В выборе языка и языковом установщике видны только Java, Python и C++; скрытые реализации остаются в исходниках.

## Автоматическая проверка

- Полная коллекция: **271 тест**.
- Проверенный итог после генерации release manifest: **269 PASS / 2 SKIPPED / 0 FAILED**, плюс **88 passing subtests**.
- Windows updater integration запускается с текущей папкой процесса внутри заменяемого каталога `Astra Studio`.
- Portable EXE запускается отдельно от исходного Python и должен показать `Astra Studio — Release 3.14`.

Два пропуска относятся к POSIX executable-bit и недоступному созданию symlink на текущей Windows-конфигурации. Предупреждение pytest касается только записи `.pytest_cache` в OneDrive-пути и не влияет на тесты приложения.
