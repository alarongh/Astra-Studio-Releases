# Astra Studio Release 4.0 — portable Windows

## Запуск

1. Полностью распакуйте ZIP в обычную доступную для записи папку.
2. Откройте папку `Astra Studio`.
3. Запустите `Astra Studio.exe`.

Не переносите один EXE отдельно: это onedir-сборка, и ей нужна соседняя папка `_internal`. Python и проектная `.venv` для запуска portable-приложения не требуются.

Пользовательские настройки и диагностический лог сохраняются вне папки приложения в локальном профиле Windows. Поэтому замена распакованной папки новой версией не должна удалять настройки пользователя.

## Обновление

В панели `Установщик` доступна команда проверки обновления приложения. Astra скачивает ZIP только после подтверждения, проверяет версию, размер, SHA-256 и структуру архива, затем закрывается, заменяет portable-папку и запускается снова. Новая версия проходит проверку запуска; при раннем завершении автоматически возвращается прежняя папка. После успеха предыдущая сборка сохраняется рядом как резервная и не удаляется автоматически.

Публичные релизы и feed находятся в репозитории `alarongh/Astra-Studio-Releases`; авторизация GitHub для загрузки не требуется.

## Angel 404

Откройте `Настройки` → `Оформление` и выберите профиль `Angel 404`. Профиль включает фиолетово-чёрную тему, обои и Minecraft Rus. Отдельно оставлены только понятные обычному пользователю параметры: обои, их затемнение/размытие, общая прозрачность панелей и шрифт. Изменение шрифта применяется ко всему тексту Astra.

Создание и выбор значка ярлыка находятся в `Настройки` → `Ярлык Windows`, а не в установщике языков.

## Если Windows блокирует запуск

Проверьте SHA-256 ZIP по файлу контрольных сумм из релиза. Если архив получен из доверенного источника и сумма совпадает, распакуйте его заново в локальную папку. Не запускайте EXE прямо из окна архиватора.
