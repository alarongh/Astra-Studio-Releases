# Изменения Astra Studio

## Release 5.0 - 28 октября 2026

Выпуск включает изменения BoyJayy из [PR #1](https://github.com/alarongh/Astra-Studio-Releases/pull/1), объединённого с `main` 28 октября, и подготовку дистрибутива 5.0. Сравнение ведётся с опубликованным Release 4.0.

### Интерфейс и оформление

- Размеры Qt, перенос текста и прокрутка учитывают крупный шрифт и масштаб дисплея. Изменение окна не сбрасывает размеры панелей и не скрывает дерево проекта.
- Добавлены однотонные фоны, палитра и проверяемые HEX-цвета рабочей области, панелей, редактора, консоли, дерева и настроек. Цвета сохраняются; предусмотрен сброс.
- Девять встроенных фотообоев заменены соответствующими цветами. Пользовательские изображения сохраняются; новые копируются под уникальными именами.
- Номера строк используют размер шрифта редактора независимо от шрифта интерфейса.

### Автодополнение и LSP

- Офлайн-подсказки и ответы готовых LSP-серверов отображаются в общем немодальном списке, включая ручной вызов.
- Исправлены позиции UTF-16, отбрасывание устаревших ответов и фильтрация строк/комментариев.
- Основная правка completion и дополнительные правки импортов проверяются и применяются атомарно.
- Исправлены сбои при удалении Qt-объектов и обратных вызовах stdio/TCP LSP-клиентов.

### Окружения и процессы

- Проверка зависимостей выполняется асинхронно, с ограничением времени и отменой; различает отсутствие пакета, ошибку и тайм-аут.
- Используются выбранный исходный корень и интерпретатор проекта. Отсутствующее окружение не приводит к скрытой установке пакетов в глобальный Python.
- Создание окружения сохраняет частично созданные окружения и существующие файлы. Повторная успешная проверка не переустанавливает зависимости.
- Исправлен жизненный цикл процессов и Qt-владельцев. На Unix остановка охватывает дочерние процессы в принадлежащем Astra сеансе.
- Диагностика инструментов macOS/Linux выполняет чтение. Проверка WinGet показывает доступные обновления без автоматической установки.

### Защита файлов и запуск инструментов

- Автозапуск LSP и фоновых проверок требует доверия к каноническому корню проекта, источнику конфигурации и подключённым исходным корням. Подмена символьной ссылки не наследует доверие.
- Проверки Python изолированы от модулей проекта; выбранный проектом интерпретатор не запускается до выдачи доверия.
- Исправлены аргументы Windows batch-файлов и передача имён файлов парсеру PowerShell.
- Проверка записи использует уникальные временные файлы. Сервер предпросмотра слушает только loopback.
- Массовая замена исключает ссылки и файлы за пределами проекта, повторно проверяет пути и сохраняет кодировку/права при атомарной записи.

Исправления закрывают выявленные в PR случаи; это не утверждение об отсутствии всех уязвимостей.

### macOS

- Нативные каталоги профиля и ресурсов, обнаружение инструментов из Finder, внешний Python и поиск JDK.
- Сочетания Command, сборка `.app`/`.dmg`, проверка подписи и фактической минимальной версии macOS.
- Абсолютный `ASTRA_DATA_DIR` позволяет проверять приложение с отдельным профилем.
- В этом выпуске поставляются Windows ZIP и исходники. macOS-пакет 5.0 на Windows не собирался; Developer ID, notarization и проверка на целевом Mac остаются отдельными действиями.

### Подготовка выпуска 5.0

- Обновлены версия приложения, название значка, метаданные EXE, macOS bundle и названия артефактов.
- При проверке на Windows исправлена горизонтальная прокрутка настроек с крупным шрифтом: длинные варианты списков больше не задают минимальную ширину страницы; сокращены подписи кнопок сброса.
- Обновлена главная страница, добавлены изменения и отчёт проверки. Старые отчёты, планы, manifests и неактуальные spec-файлы перенесены в `docs/history`.
- Windows build использует `astra_studio.spec`. Упаковщик исключает Git-метаданные, окружения, кэши и результаты сборки; в checkout берёт tracked/staged-файлы.
- Правило `.gitattributes` сохраняет CRLF в Windows `.bat`-файлах при checkout на любой платформе.
- Для Windows ZIP и исходников выпускаются SHA-256; feed указывает на опубликованный ZIP 5.0.
