# Проверка Astra Studio Release 5.0

Дата: 28 октября 2026. Среда: Windows 11 x64 (build 26200), CPython 3.14.7, PySide6 6.11.2, PyInstaller 6.22.2, pytest 9.1.1. Зависимости установлены в отдельное локальное окружение.

Исходная точка: объединённый PR #1, commit `a2bd13c85bbe8b76ea0d37a4358ac0a5fc83ffe8`. Изменения выпуска перечислены в [CHANGELOG.md](CHANGELOG.md). Проверка автора PR на macOS сохранена отдельно в [истории](docs/history/VALIDATION_PR_1.md) и не подменяет проверку этого Windows EXE.

Пропуски: пять POSIX/macOS-specific случаев и пять проверок, для которых этот Windows-профиль не разрешает создание символьных ссылок. Пропуски не считаются успешной проверкой этих сценариев. Реестр: [docs/TEST_REGISTRY.md](docs/TEST_REGISTRY.md).

Начальный Windows-прогон выявил пять падений проверки ширины страницы настроек. Причина: длинные элементы QComboBox и подписи кнопок задавали минимальную ширину страницы больше viewport. Ограничена минимальная ширина списков, подписи кнопок сокращены/перенесены. Существующие проверки сохранены и прошли повторно.

Ещё одно падение относилось к тесту POSIX-корней на Windows: `WindowsPath('/opt/homebrew/bin').is_absolute()` использует другую семантику. Для двух фиксированных macOS-корней проверяется `PurePosixPath`, для путей домашнего каталога - нативная семантика хоста. Поведение приложения этим исправлением теста не меняется.

## Нативный portable EXE

Приложение запущено из собранной папки с отдельным `ASTRA_DATA_DIR` и копией пользовательского оформления. В обычном Windows-окне проверены:

- заголовок `Astra Studio - Release 5.0` и загрузка ресурсов;
- открытие Python-файла, запуск F5 и ввод `42` в консоль;
- результат `ASTRA_5_OK 43`, завершение с кодом 0;
- повторный запуск и остановка программы, ожидающей ввод;
- возврат основной кнопки в состояние запуска;
- сохранение Ctrl+S и штатное закрытие Alt+F4.

## Дистрибутив

Portable ZIP содержит всю папку `Astra Studio`, EXE, `_internal`, данные, настройки update-channel и README. Архив исходников содержит текущие исходники и историческую документацию; Git-метаданные, окружения, кэши и результаты сборки исключаются. Для исходников создаётся отдельный `RELEASE_MANIFEST_5_0.sha256`, для двух ZIP - `SHA256SUMS.txt`.

`update/latest.json` генерируется по фактическим размеру и SHA-256 готового Windows ZIP. Публиковать feed следует после загрузки release asset.

## Границы проверки

В этом выпуске не собирался macOS-пакет 5.0, не проверялись Intel/universal2, старые версии macOS и переходы между физическими мониторами с разным DPI. WinGet не запускался на установку/обновление toolchains. Полная ручная owner-матрица и все сочетания внешних LSP/компиляторов не заявляются проверенными.

CI Windows/macOS запускается workflow `.github/workflows/ci.yml`; актуальный статус конкретной ревизии следует смотреть в GitHub Actions. Этот отчёт фиксирует выполненную локальную проверку и не выдаёт наличие workflow за успешный CI-прогон.
